# RCPP RDF 검증 보고서


## 1. 검증 대상

- RDF 데이터 파일
  - 경로: `KO/RDF/rcpp-rdf.ttl`
  - 직렬화 형식: Turtle
  - 역할: RCPP 온톨로지의 독립 RDF 인스턴스 데이터(ABox)
  - 구성: 공종·단위 기준 개체, 기성회차, 기성문서, 비용항목, 문서항목 및 정보계보


## 2. 세부 검증 결과

### 2.1 RDF/Turtle 구문 검증

- 검증 내용
  - 접두어 선언과 IRI 표현 확인
  - 주어·술어·목적어 트리플 구문 확인
  - 리터럴, 언어 태그 및 XSD 데이터형 파싱 확인
  - 파일 전체를 독립 RDF 그래프로 로드할 수 있는지 확인
- 결과
  - Turtle 파싱: **통과**
  - 파싱된 RDF 트리플: **748개**
  - 외부 RDF 파일 병합 없이 단독 로드: **가능**

### 2.2 RDFS 추론 적용 검증

- 검증 내용
  - `rdfs:subClassOf` 계층을 이용한 상위 유형 판정
  - 구체 문서 유형을 `ProgressDocument`로 판정
  - 구체 비용항목 유형을 `CostItem`으로 판정
  - 구체 문서항목 유형을 `DocumentItem`으로 판정
  - RDFS 정의역·치역 및 클래스 계층을 SHACL 검증에 제공
- 결과
  - RDFS 추론 적용: **통과**
  - 상위 클래스 기준 핵심 개체 탐색: **통과**

### 2.3 SHACL 구조 및 값 제약 검증

- 검증 내용
  - 필수 속성의 존재 여부(`sh:minCount`)
  - 단일값 속성의 최대 개수(`sh:maxCount`)
  - 문자열·정수·소수 등 데이터형(`sh:datatype`)
  - 참조 개체의 클래스(`sh:class`)
  - 0 이상·양수 등 수치 범위
  - 공종·강종·타설방법·구조물 유형 등 통제값 목록
  - 문서가 포함할 수 있는 항목 유형
  - 문서항목과 표준 비용항목의 대응 관계
  - 계약수량·계약단가·계약금액의 전달 원천 일치
  - 산출수량 합계와 계약수량의 일치
  - 원가 구성비 합계와 산출단가의 일치
  - 전회·금회·누계·잔여 수량 및 금액의 산술 일관성
  - 이전 기성회차와 전회누계 전달 관계의 일관성
  - 공종별 계약금액 및 기성금액 집계의 일관성
- 적용 제약 규모
  - `sh:minCount`: 68개
  - `sh:maxCount`: 61개
  - `sh:datatype`: 48개
  - `sh:class`: 26개
  - 통제값 목록(`sh:in`): 13개
  - SPARQL 제약: 28개
- 결과
  - SHACL 적합성: **통과**
  - 검출된 SHACL 위반: **0건**

### 2.4 핵심 업무 개체 존재 검증

- 검증 방법
  - RDF에 직접 선언된 `rdf:type` 확인
  - 직접 유형이 상위 클래스가 아닌 경우 `rdfs:subClassOf`의 추이적 경로를 따라 상위 유형으로 집계
- 결과
  - 기성회차(`ProgressPaymentRound`): **3개**
  - 기성문서(`ProgressDocument` 및 하위 유형): **7개**
  - 비용항목(`CostItem` 및 하위 유형): **7개**
  - 문서항목(`DocumentItem` 및 하위 유형): **55개**
  - 공종(`WorkCategory`): **5개**
  - 단위(`Unit`): **4개**
  - 모든 필수 업무 유형 존재: **통과**
